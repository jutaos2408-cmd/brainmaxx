Strava & Garmin hochladenDatei aus der Strava- oder Garmin-App wählen. FIT, GPX, TCX, CSV, JSON und ZIP gehen alle.
WAS GENAU HOCHLADEN?
  • Strava, eine Aktivität: Aktivität im Browser öffnen → „⋯“ → GPX exportieren oder Original exportieren (FIT).
  • Strava, alles: Einstellungen → Mein Konto → Archive herunterladen. Die ZIP direkt hochladen, activities.csv wird automatisch gelesen.
  • Garmin, eine Aktivität: Garmin Connect → Aktivität → Zahnrad → Original exportieren (ZIP mit FIT).
  • Garmin Schlafscore als CSV: Garmin Connect im Browser → Berichte/Schlaf → Zeitraum wählen → Export (CSV).
  • Garmin, alles inkl. Schlaf, Ruhepuls, Body Battery, Stress, Schritte: Garmin-Konto → Datenverwaltung → Daten exportieren. Die ZIP aus der Mail direkt hochladen.
  • Importiert werden die letzten 120 Tage. Doppelte Aktivitäten werden erkannt.
